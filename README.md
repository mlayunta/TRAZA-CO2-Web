# TRAZA//CO₂

Calculadora interactiva de CO₂e para analizar el efecto de medidas de eficiencia en energía de manipulación, bajas de inventario y huella digital incremental en operaciones WMS con IA.

**Autor y responsable de la publicación:** Miguel Ángel Layunta López

## Funcionalidades

La página incorpora una calculadora anual editable, dos gráficos dinámicos que se actualizan en tiempo real, una comparación entre línea base y escenario posterior, y la descarga local de un informe PDF con el resultado activo.

## Publicación

Este repositorio está listo para desplegarse con GitHub Pages. Consulte la guía completa en [`GUIA_GITHUB_PAGES.md`](GUIA_GITHUB_PAGES.md). Para una publicación rápida, active **Settings** → **Pages**, elija **Deploy from a branch**, seleccione `main` y la carpeta `/(root)`.

## Nota metodológica

La calculadora ofrece una estimación orientativa. Antes de emplear sus resultados para comunicar o reportar emisiones evitadas, sustituya los factores y supuestos por datos medidos y fuentes verificables del centro operativo.
